A simple menu-driven Calculator built in Java.
It supports basic arithmetic operations like Addition, Subtraction, Multiplication, Division, and Modulus.

📌 Features
 - Console-based calculator
 - Supports 5 operations:
    - ➕ Addition
    - ➖ Subtraction
    - ✖️ Multiplication
    - ➗ Division
    - ％ Modulus
 - Menu-driven system (choose operations by number)
 - Option to continue or exit after each calculation
 -Handles invalid operation inputs gracefully

🛠️ Technologies Used
 - Java (Core Java)
 - Scanner class for user input
 - Switch-case for menu handling

▶️ How to Run

Compile the program:
 - javac Calculator.java
Run the program:
 - java Calculator
